## 1. 系统简介

AI Testing Intelligence 是一套 AI 智能测试情报系统，围绕以下工作流运行：

- **发现**：从配置的信源持续采集 RSS / Atom / 网页内容；
- **分析**：由 AI 模型评估内容的测试相关性、测试价值，生成摘要、适用场景、落地建议与风险；
- **去重**：按原文 URL 或标准化标题进行历史去重，避免转载链接等 URL 不同的重复内容；
- **交付**：在「内容情报」中以情报卡片展示，并支持导出合并的 Markdown 测试报告。

系统通过浏览器访问管理界面，具体访问地址由系统管理员提供。首次使用前，请确认已获得有效账号；为获得完整的页面和下载功能，建议使用近期版本的主流浏览器。

## 2. 角色与权限

系统内置三种角色，权限由低到高：

| 角色 | 权限 |
| --- | --- |
| 浏览者（viewer） | 查看和筛选「内容情报」、查看情报详情、导出 Markdown 报告；查看信源及其采集端点 |
| 维护者（maintainer） | 在浏览者基础上，可自动发现、新增和编辑信源，管理采集端点，为微信/微博信源人工录入内容 |
| 管理员（admin） | 在维护者基础上，可删除信源、管理采集内容、管理用户、查看数据库状态 |

各功能页面按角色显示：浏览者只看到「内容情报」和「信源管理」，维护者额外可进行信源与端点维护操作，管理员还能看到「采集管理」「用户管理」「数据库状态」三个页面。

## 3. 登录与退出

1. 在浏览器打开系统地址，进入登录页。
2. 输入管理员分配的用户名和密码，点击「进入雷达」。
3. 登录成功后进入仪表盘；用户名和角色显示在右上角。

> 提示：登录状态保存在当前浏览器本地，请勿在公共设备上保留登录状态。会话失效后系统会自动登出，重新登录即可。右上角的退出按钮可随时手动退出。

## 4. 内容情报

「内容情报」展示已完成分析、达到系统测试相关性门槛，并满足当前最低价值分条件的情报卡片，是日常浏览的核心页面。默认每页显示 12 条，并优先显示测试价值分较高的内容。

### 4.1 检索与筛选

工具栏提供以下筛选条件：

- **关键词检索**：检索标题、摘要或正文，回车或点击「检索」生效；
- **开始/结束日期**：优先按内容发布时间筛选；没有发布时间时，使用采集时间。结束日期不得早于开始日期；
- **最低价值**：选择「观察 40+」「推荐 60+（默认）」或「高价值 80+」。该条件仅调整测试价值分门槛，不会绕过系统配置的测试相关性门槛；
- 「应用筛选」确认条件，「重置」恢复默认（清空关键词和日期，价值分回到 60）。

筛选或翻页时页面会短暂显示加载状态。若刚完成采集或分析但列表未更新，可等待片刻后重新进入该页面或再次应用筛选。

### 4.2 查看情报详情

点击卡片标题或「查看测试情报」，弹出详情窗口，包含：

- 情报摘要；
- 测试价值分析；
- 适用测试场景、落地验证建议；
- 风险与边界；
- 高价值内容原文中提炼出的相关工具、研究、会议或参考资料链接；
- 标签、相关性分与价值分；
- 「查看原文」跳转到外部原文链接（在浏览器新标签页打开）。

### 4.3 导出 Markdown 报告

1. 勾选要导出的情报卡片（支持跨页选择，单次最多 100 条）；可用「全选当前页」或「清空选择」快速操作；应用新的筛选条件或重置筛选会清空当前选择；
2. 点击「导出 Markdown (N)」；
3. 浏览器自动下载合并的 Markdown 报告文件。

报告按选择顺序输出，包含每条情报的评分、测试价值分析、适用场景、落地建议、风险、标签、相关链接和原文证据链接，可直接用于测试评审或归档。若浏览器阻止自动下载，请允许当前站点下载文件后重试。

测试价值达到 60 分的内容完成分析后，后台会分批受限读取一次原文页面，从原文实际存在的链接中最多提炼 5 条相关资料。链接由程序确定性提取，不要求模型生成 URL，也不会继续抓取链接指向的页面；未找到合适链接时不显示该区域。外部链接内容不受本系统控制，访问前仍应核对域名和来源。

## 5. 信源管理

「信源管理」以卡片形式展示所有已配置的信源节点，并显示可信等级、语言与关注主题。页面顶部「监听节点」统计信源总数和「高可信信号」数量。

### 5.1 新增信源（维护者/管理员）

点击「新增信源」，填写：

| 字段 | 说明 |
| --- | --- |
| 信源名称 | 必填，全局唯一 |
| 信源类型 | 网站 / 通讯 / RSS / 社交媒体 / 微信公众号 / 微博 |
| 可信等级 | 1-5：5 最高可信、4 高可信、3 待验证、2 观察中、1 低可信 |
| 主页地址 | 可选，需为有效 URL |
| 描述 | 可选，信源说明 |
| 语言 | 必填，多个值用逗号分隔，如 `zh-CN, en` |
| 关注主题 | 界面要求填写，多个值用中文或英文逗号分隔，如 `AI Agent, foundation-models` |

点击「建立监听」保存。新建信源后，还需按 5.4 节添加采集端点，系统才能自动采集内容；微信公众号和微博也可按 5.5 节人工录入。信源名称重复时系统会提示冲突。

RSS / Atom 端点如果误填为栏目网页、发生跳转或原地址失效，系统会从当前响应或信源主页读取网站声明的订阅地址，并在当前站点内有限探测常见订阅路径。只有候选地址能够解析出有效条目时才会自动修正端点；无法确认时会保留原配置并将端点标记为异常，不会调用搜索引擎或无限尝试。对于缺少摘要的少量新条目，系统会受限读取文章页的描述信息作为补充。

### 5.2 自动发现信源（维护者/管理员）

点击「自动发现」，输入网站主页后选择「开始探测」。平台会读取网站声明的 RSS / Atom 地址，并在当前站点内有限验证常见订阅路径。发现成功后会展示已验证的订阅地址和最近文章样例。

确认样例符合预期后，填写信源名称、语言、可信等级和关注主题，点击「确认并启用监听」。服务端会再次验证订阅地址，并一次性创建已启用的网站信源和健康的 RSS / Atom 端点；端点默认每 360 分钟采集一次、单次最多 50 条。验证失败或名称冲突时不会留下半成品信源。浏览者没有发现或创建权限。

### 5.3 编辑与删除信源

- **编辑**（维护者/管理员）：点击卡片「编辑」修改字段后保存；
- **删除**（仅管理员）：点击「删除」并确认。删除会级联清除该信源的全部采集内容且无法恢复，请谨慎操作。

### 5.4 管理采集端点

点击卡片「采集端点」打开端点抽屉。所有角色均可查看端点，维护者和管理员可新增或删除端点。

新增端点时填写：

| 字段 | 说明 |
| --- | --- |
| 端点名称 | 必填，如「官方 RSS」 |
| 采集类型 | RSS / Atom 或网页；微信公众号、微博仅允许 RSS / Atom |
| 采集间隔（分钟） | 15 - 10080，默认 360；表示两次计划采集的最短间隔 |
| 采集地址 | 必填，需为有效 URL；生产环境建议使用 HTTPS |
| 单次最大条数 | 1 - 500，默认 50；仅表示一次处理的条目上限 |

点击「添加采集端点」保存。新端点由后台采集任务按轮询周期异步处理，不保证保存后立即出现内容。

端点列表会显示健康状态：`unknown` 表示尚未完成采集，`healthy` 表示最近一次采集成功，`unhealthy` 表示最近一次采集失败。RSS / Atom 端点异常时，平台会先按上述规则自动发现并验证替代地址；仍未恢复时，再检查地址可访问性、内容格式和 Worker 日志。

删除端点时点击端点右上角删除按钮并确认。删除后，该端点的配置和采集运行历史无法恢复，但已采集内容仍保留；如需删除内容，由管理员在「采集管理」中操作。

### 5.5 人工录入内容（微信/微博，维护者/管理员）

微信公众号、微博信源卡片上会出现「录入内容」按钮。系统不会抓取平台页面，而是使用你填写的信息进入去重与情报分析流程。填写：

- 内容标题（必填，最多 500 个字符）；
- 原文地址（必填，有效 URL）；
- 内容摘要（必填，最多 20000 个字符，建议包含关键事实与测试价值线索）；
- 发布日期（可选）。

点击「提交分析」后，内容进入异步分析队列，不会立即出现在「内容情报」。管理员可在「采集管理」中查看处理状态；分析通过且达到相关性和价值门槛后，才会进入「内容情报」。相同原文地址或标题只能录入一次，重复提交会提示内容已存在。请确保内容来源合法并保留原文证据链接。

## 6. 采集管理（管理员）

「采集管理」展示自动采集和人工录入的全部内容，包括待分析、已入雷达、已过滤和分析失败的记录。默认每页显示 20 条，按采集时间倒序排列。

状态含义如下：

| 状态 | 含义 |
| --- | --- |
| 待分析 | 内容已经入库，等待后台分析任务处理 |
| 已入雷达 | 已通过测试相关性判断并生成情报结果 |
| 已过滤 | 未达到测试相关性要求，或缺少可执行的测试场景/建议，不进入情报流 |
| 分析失败 | 模型调用或结果处理失败；后台会按计划自动重试 |

### 6.1 查询与筛选

- **关键词查询**：查询标题或摘要；
- **分析状态**：待分析 / 已入雷达 / 已过滤 / 分析失败；
- **信源**：按信源过滤；
- **开始/结束日期**：按采集时间过滤。

设置条件后点击「应用筛选」；需要清除条件时点击「重置」。

### 6.2 查看采集详情

点击内容标题可查看原始摘要、信源、分析状态、相关性与价值评分、分析次数、发布时间、采集时间和分析时间。高价值内容若已从原文提炼出相关资料，也会显示「相关链接」。分析失败的内容还会展示完整失败原因；点击「查看原文」可在新窗口打开外部原文地址。

### 6.3 删除采集内容

- **单条删除**：点击某行右侧删除按钮并确认；
- **批量删除**：勾选多条（单次最多 100 条）后点击「批量删除 (N)」并确认。

删除某条采集内容会同时删除其分析结果，并从「内容情报」移除，但不会删除信源或采集端点。列表可能需要短暂刷新才能反映变化。删除操作不可撤销；批量删除中只要包含不存在的记录，本次批量操作就不会执行。

> 说明：分析失败的行会以红色状态显示，悬停可见失败原因，便于排查采集或分析配置问题。

## 7. 用户管理（管理员）

「用户管理」列出所有账号，支持新增、编辑、停用/启用和删除。

### 7.1 新增用户

点击「新增用户」，填写：

- 用户名（必填、唯一，最多 100 个字符）；
- 初始密码（8 - 200 个字符）；
- 角色：浏览者 / 维护者 / 管理员；
- 账号状态：启用 / 停用。

点击「创建用户」保存。用户名重复时系统会提示冲突。

系统当前不提供用户自助修改密码功能。用户忘记密码时，应联系管理员通过「编辑用户」设置新密码；管理员应通过安全渠道告知新密码。

### 7.2 编辑用户

点击「编辑」可修改用户名、角色、账号状态，或设置新密码（留空则不修改）。停用后的用户将无法继续通过系统鉴权。系统有以下保护规则：

- 不能停用自己的账号；
- 不能移除系统最后一个启用的管理员；
- 不能把必要字段清空。

### 7.3 删除用户

点击「删除」并确认。以下情况无法删除：

- 当前登录用户自己（删除按钮对本人置灰）；
- 最后一个启用的管理员；
- 拥有信源的用户。当前 Web 界面不支持转移信源所有权，需先由管理员删除该用户拥有的信源，再删除用户。

## 8. 数据库状态（管理员）

「数据库状态」显示当前存储引擎（dialect）与核心数据表行数：

- 用户；
- 信源；
- 采集端点；
- 内容条目；
- 采集运行。

该页面仅用于快速了解数据资产规模，不提供修改能力。页面数据可能存在短时间缓存，刚完成新增或删除后可稍候再重新进入页面查看。

## 9. 常见问题

**Q：为什么「内容情报」里什么都没有？**
未配置 AI 分析模型时，采集的文章会停留在待分析状态，情报流保持为空，避免把未经评审的普通 AI 新闻混入。请管理员按部署手册配置 OpenAI 兼容的分析模型。

**Q：为什么有些已采集的内容没有出现在「内容情报」？**
内容可能仍在等待分析、分析失败、未达到系统相关性要求，或测试价值分低于当前页面筛选值。管理员可在「采集管理」中查看其状态及评分。

**Q：重复内容会被重复采集吗？**
RSS / Atom 内容和人工录入内容按原文 URL 哈希或标准化标题去重，重复 URL、转载链接或同标题内容会被跳过或拒绝。网页类型端点会定期更新同一 URL 的内容并重新进入分析，而不是创建重复记录。

**Q：微信/微博为什么不能配置网页类型端点？**
平台页面存在访问与版权边界，系统仅接受来源明确、已获授权的 RSS / Atom 地址；平台内容通过「录入内容」人工提交，且不会自动抓取页面。

**Q：导出的报告为什么有条数限制？**
单次报告最多选择 100 条情报，超出部分需分批导出。

**Q：登录时提示「登录状态已失效」？**
登录令牌过期或会话失效，重新登录即可。

**Q：端点显示 `unhealthy` 怎么处理？**
系统会先尝试从当前响应或信源主页发现新的 RSS / Atom 地址，并有限验证同站常见订阅路径；成功后会自动更新端点。若后续采集仍显示 `unhealthy`，再确认目标站点能从服务器访问、没有拒绝请求，并联系管理员检查 Worker 日志。普通用户无法查看详细采集错误。

**Q：页面提示网络异常或请求失败怎么办？**
先刷新页面并重试；若持续出现，记录当前页面、操作步骤和提示文字，联系管理员检查 API、Worker、数据库和网络状态。不要反复提交新增或删除操作，以免造成重复请求。
